VR-Test Haupteingang

1. Diese drei Dateien in ein neues GitHub-Repository hochladen:
   - index.html
   - haupteingang.jpg
   - README.txt
2. GitHub Pages aktivieren: Settings > Pages > Deploy from a branch > main > /(root)
3. Die GitHub-Pages-Adresse im VIVE Browser öffnen.
4. Auf "VR starten" klicken.
5. Erfolgreicher Test: Panorama füllt das komplette Sichtfeld und folgt den Kopfbewegungen.

Hinweis: Diese Version dient nur zum Test des immersiven WebXR-Modus. Die sichtbaren Panorama-Nähte werden erst nach erfolgreichem Headtracking-Test bereinigt.
